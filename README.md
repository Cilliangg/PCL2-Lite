# PCL2-Lite
> 基于 [PCL2](https://github.com/Hex-Dragon/PCL2) 2.14.0.0 的**非官方精简改版**：留下下载，去掉其余。

把 PCL 里用不上的页面全部摘掉，导航从 5 项减到 3 项，启动即进入下载页；「更多」页重构成一个**多线程下载工具**——粘贴链接就能下任意文件。界面、翻页动画、提示弹窗全部沿用 PCL 原生实现，没有任何拼凑感。

## 和官方版的差异

| 项目 | 官方 PCL2 | PCL-Lite |
| --- | --- | --- |
| 启动页 | 有 | **已移除**，启动直接进下载页 |
| 个性化设置 | 完整的一页 | **已移除**（你已配置的外观仍然保留） |
| 设置 → 辅助功能 / 启动器 / 调试选项 | 有 | **已移除** |
| 更多页 | 帮助 / 关于 / 百宝箱 / 反馈 / 投票 | **只保留「下载自定义文件」** |
| 第三个标签页 | 更多 | **多线程下载** |
| 启动行为 | 仅版本变化时弹更新日志 | 额外弹一次说明窗 |

## 主要特性

- **干净**：没有启动页、没有个性化、没有调试选项，进来就是下载
- **多线程下载**：PCL 的高速下载引擎单独拎出来，粘链接即下
- **原生手感**：圆角卡片、切换动画、说明弹窗全是 PCL 自己的组件
- **单文件绿色版**：一个 exe，不写注册表，配置跟着目录走

## 适用场景

- 主要拿 PCL 下整合包 / 资源包 / 模组，不想在设置里绕
- 已经把 PCL 当下载器用，希望它更纯粹
- 需要给不太会操作的人装一个"不容易点错"的版本

## 快速开始

1. 从 [Releases](../../releases) 下载 `PCL-Lite.exe`
2. 放进任意目录（建议单独文件夹），双击运行
3. 首次启动会弹一次说明，点「确定」即可

> ⚠️ **当前版本以资源下载为核心，未保留启动页入口。**&#8203; 如果你需要一键启动游戏，请使用官方 PCL2。
